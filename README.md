# Portfolio de Carlos León

Portfolio estático realizado con HTML, CSS y JavaScript, sin dependencias.

## Estructura

- `index.html`: contenido y estructura.
- `styles.css`: diseño responsive y animaciones.
- `script.js`: navegación móvil, animaciones, vídeo y avisos.
- `assets/videos/`: demos de los proyectos.
- `assets/img/`: miniaturas de los vídeos.

## Antes de publicar

Edita en `index.html` los tres enlaces marcados con la clase `placeholder-link`:

1. LinkedIn: sustituye `href="#"` por tu URL.
2. CV: coloca el PDF, por ejemplo en `assets/Carlos-Leon-CV.pdf`, y usa esa ruta en `href`.
3. Email: usa `href="mailto:tu@email.com"`.

## Publicación

Al ser una web estática puedes publicarla directamente en GitHub Pages, Netlify, Vercel o cualquier hosting web.

### Importante sobre los vídeos

Los dos MP4 pesan alrededor de 220 MB en total. Para producción conviene comprimirlos o alojarlos externamente si el hosting tiene límites de tamaño o ancho de banda.
